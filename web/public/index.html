    Help, interpretation and limits

    Choose a workflow, edit every relevant parameter or import your supported local file, then run. The C++ engines decide outcomes; the application checks their source, request fingerprint, exact wire CRC and byte accounting before retaining evidence. A completed run is a simulated observation, not permission to control a device.

    Session rows show the actual affected bytes before and after each operation. A corrupt write response can follow a successful memory mutation; review the subsequent read and trace. Read retries reuse the logical request ID; write retries require another explicit operation.

    Stream offsets are zero-based byte offsets in concatenated input; known discarded extents, accepted frames and omitted-issue byte totals account for the complete stream, including EOF. Empty input is reviewed, not invented as a valid frame.

    Exported evidence includes exact input and engine identity. Reimport reruns input with the actual current engine and ignores supplied result claims. Raw-frame export includes only an accepted selected frame. Back up the stopped workspace outside this installation. There are no remote accounts, cloud uploads, third-party ads or telemetry.
