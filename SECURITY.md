# Security policy

## Supported versions

The `main` branch is the only supported educational version.

## Reporting

Use GitHub's private vulnerability reporting feature when available. Otherwise contact the repository
owner privately through the contact method on the GitHub profile. Do not open a public issue containing
an exploit, credential, customer information, or non-public protocol material.

Include the affected commit, smallest reproducer, expected/observed behavior, impact, and whether the
issue reproduces under ASan, UBSan, or the fuzz target.

## Scope reminder

The project is a local synthetic simulator, not a device protocol, network service, or security
product. Reports about its parser, range checks, authorization policy, CI, or dependencies are useful.
Claims that it does not connect to a commercial device are expected behavior, not vulnerabilities.
